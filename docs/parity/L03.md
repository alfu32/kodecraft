# L03 — Kotlin semantic extraction

Status: done. Source baseline: `7d3e5953ec2de75f2b5e9c44fb3e65549d39ec68`.
Summary: `feat(intelligence): extract Kotlin semantic facts from native trees`.

`kode-intelligence/src/frontend/kotlin/` consumes L02's immutable parsed document
or owns a reusable per-document parser. It emits L01 file deltas with byte-based
identities, declarations and name ranges, nested file/package/type/function/block/
lambda scopes, imports and aliases, visibility, ownership, unresolved declared/
parameter/return/super types, lexical tokens and literal expression records.
Constructor property parameters become members; constructor-only parameters remain
lexical declarations. Locals retain function ownership and scope, without becoming
object members. Generic/nullable type spelling is retained for the resolver.

Initializer and assignment hints distinguish references, constructor/function
calls, casts, literals, `this` and `super`. Member occurrences link actual receiver
occurrences through chains, with unresolved identity until L06/L07. Navigation
initializers do not infer a type from their first identifier. String interpolation
uses the selected grammar's expression/interpolated-identifier nodes; escaped
dollars are excluded. L06 requalifies the frontend with ast-grep's Kotlin binding
0.4.1 after finding a declaration-loss case in kotlin-ng 1.1.0. Integer/real/long/
hex/binary literals, identifier wrappers, statement-body scopes, import lists,
navigation suffixes and constructor binding nodes use the selected AST. The nine
extraction tests pass unchanged after that binding correction.

[The synthetic extraction fixture](../../fixtures/languages/kotlin/extraction.kt)
and nine `tests/kotlin_extraction.rs` tests cover:

- Source identifier-pipeline declaration/qualified-name scenarios, package/import
  aliases, constructor fields, visibility, nested declarations and Unicode ranges.
- Generic/nullable references, superclass/interface facts, primitive literal shapes,
  short/explicit/raw interpolation, escaped dollars and punctuation-free names.
- Shadowing, declaration order and assignment targets through real L01 snapshots.
- Incomplete/empty/backtick/CRLF/emoji inputs and valid partial deltas.
- Identical fresh/reused extraction through Unicode, length and type edits;
  prior deltas remain stable, cancellation and excessive depth fail explicitly.
- Source vertical-slice surface hashing: local body changes preserve the hash;
  declared return type and declaration movement change it.
- Completion receiver ranges for chains, calls, casts, indexing and safe access.
