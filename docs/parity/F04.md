# F04 — Terminal lifecycle and normalized input

**Status:** done

Source baseline: `7d3e5953ec2de75f2b5e9c44fb3e65549d39ec68`.
Toolchain tested: Rust/Cargo 1.99.0 stable, Linux x86_64.

Changed paths: TUI `terminal/`, `input/terminal.rs`, normalized input tests,
actual Crossterm terminal probe and `scripts/test-terminal.py`.
Source UI events, ANSI PageDown regression, terminal utilities and backend
implementations were read before adoption.

One `TerminalSession` exclusively owns raw mode, alternate screen, cursor,
mouse/focus reporting, bracketed paste and the single synchronous input source.
RAII restores modes after errors, normal exit and partial initialization. A panic
hook restores the UI terminal before reporting a main-thread panic; worker panics
go to the supplied file log and typed runtime result rather than the canvas.

Key normalization preserves printable case and modifiers, translates Enter/CR/LF,
NUL completion and BackTab, distinguishes repeats, and excludes release edits.
Pointer capture events, wheel axes, focus, paste and resize retain typed values.
Enhanced keyboard reporting is queried only before input polling starts, enabled
when supported and popped during restoration. Classic bindings remain usable.

Suspension disables polling before leaving terminal modes. A shell child reads
canonical stdin with the editor reader stopped. Resume re-enters modes and resets
only rendering buffers for a complete redraw. The initial PTY experiment caught
Ratatui `Terminal::clear` querying the cursor and timing out; resume now rebuilds
its backend buffers without requiring a cursor-position response.

## Validation

Passed: input unit tests (three normalization suites), actual custom-widget backend
build, `cargo fmt --all --check`, focused TUI `cargo clippy --all-targets --offline
-- -D warnings`, and **17 actual PTY cases** in [F04-pty.json](F04-pty.json).
Normal/error/panic paths run at 80×24, 120×40, 20×6 and 1×1; all restore the exact
original termios flags and emit alternate-screen, paste and cursor restoration.
Standalone `ESC [6~` produces PageDown without an additional input byte. NUL opens
the normalized completion binding; actual bracketed UTF-8 paste produces one
paste event. A shell reads `hello-shell` while suspended and the terminal resumes.
An emulated capable terminal confirms enhanced keyboard detection.

Acceptance: UX-003/020/077/107 at the terminal boundary. Full editing semantics
and application shell composition remain with their dependent owners.

Commands: `cargo test --offline -p kode-tui`; `cargo build --offline -p kode-tui
--example terminal_probe`; `python3 scripts/test-terminal.py`; fmt/clippy above.
No Rust terminal adapter uses raw escape decoding independent of Crossterm.
Windows release/repeat normalization is tested with typed events; macOS uses the
same Unix adapter. Actual Windows/macOS/SSH/tmux/browser checks remain Z04.
