external host suggestions and bounded worker execution. Host suggestions precede

the current logical line. Native/provider work never occurs in rendering.

late results. Errors remain typed and visible to the host rather than becoming
empty success. Explicit requests remain available with automatic external display
disabled. An enabled host can request automatic suggestions for a nonempty typed
prefix; accepting a completion does not immediately reopen the list.

track clicks. Enter/row click applies insertion text and validated replacement

from its label. Fallback ranges replace only the typed identifier prefix and
preserve receiver/suffix. Read-only documents reject acceptance at the core.

even beyond the pane, so they cannot start an underlying selection. Wheel outside
the popup dismisses and continues editor scrolling. Input now calls hook context
invalidation after core changes as well as before popup routing.
