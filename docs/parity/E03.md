# E03 — Editing, auto-indent, undo and redo

**Status:** done

Source baseline: `7d3e5953ec2de75f2b5e9c44fb3e65549d39ec68`.
Toolchain tested: Rust/Cargo 1.99.0 stable, Linux x86_64.

Changed paths: core `editor/{edit,history}.rs`, document mutation delegation,
editing tests and shared contracts. Source mutation/history/newline/deletion and
undo/input regression assertions were read before implementation.

Insert/replace, forward/reverse selection deletion, scalar-safe backspace/delete,
line joins and copied leading indentation produce typed deltas and monotonic
revisions. CRLF joins/newlines preserve the file's break style. Every mutation
uses the same revision/capability boundary. Multiple disjoint original-source
replacements apply in descending order and commit as one atomic revision/undo
transaction; paste/completion/replace-all therefore remain compound actions.
Overlap/invalid/stale/no-op edits do not partially mutate state or create history.

Undo/redo restore source and cursor/anchor state, including reverse selections and
the source's redo behavior of retaining the cursor present when undo was requested.
New edits clear redo; no-op edits retain it. Dirty state compares current content
with the saved baseline, so undoing back to saved text clears dirty even after
monotonic revisions advance. This intentionally strengthens the old snapshot's
stored dirty flag. Read-only documents reject typing, paste, deletion, programmatic
replacement, transactions, undo/redo and history import.

History uses shared rope snapshots without holding old worker text caches. Runtime
limits are 200 transactions and 64 MiB of changed text. Capacity removals are
reported by each edit outcome. Versioned history JSON retains current/saved text,
revision/caret, both stacks and omitted counts; export keeps up to 30 states per
stack within a shared 64 MiB serialized history budget. Import validates retained
scalar boundaries and schema version before committing, reports trimming and
never silently drops current dirty text. W03 consumes the omission metadata when
presenting restored-state limits.
