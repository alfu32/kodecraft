# G02 — Stage, unstage, commit, checkout and tags

Task: G02. Status: done.
Source baseline: `7d3e5953ec2de75f2b5e9c44fb3e65549d39ec68`; reference tree clean.

Read IGitService/JGitService's write implementations and all GitPanelView handlers.
Local operations use pinned git2/libgit2 in F03 blocking jobs; the interactive
thread owns models, common editor hosts and tagged acknowledgements. No Git shell,
JGit, hooks, remote service or JVM is needed by the application.

Stage and unstage support literal single/multiple paths, deletions, unborn HEAD
and resolved conflicts. A standard owned index.lock protects a private attached
index transaction; preparation failures leave the original index intact, and
another writer's lock is preserved. Publication syncs prepared bytes and renames
the owned lock. Paths reject metadata/parent escapes and unsafe parent links.
Ignored new paths and unsupported ordinary directory staging produce explicit errors.

Commit validates configured nonblank identity, nonempty/NUL-free bounded message,
staged changes, conflicts and repository operation state. It commits the captured
staged tree, preserving index and worktree. Annotated tag creation refuses an
existing name unless the explicit create/move action is used; invalid targets
never first delete the existing tag. Full branch/tag names retain their hierarchy.

Checkout uses safe native checkout with ignored-file overwrite disabled, locks
the index/affected refs, rejects tracked local changes and branches used by another
worktree, and never silently forces. Application checkout additionally refuses dirty
text/binary buffers, active session persistence and changes to this open workspace's
session/cache paths. Accepted writes drain before quit/workspace disposal.

Alt+5 composes status, a shared virtual commit editor, draggable separators and
expandable history/file lists. Space stages/unstages, a/A operates on all rows;
Tab enters the editor, ordinary Tab keeps editor behavior, and Ctrl+Tab cycles
sections. Ctrl+Enter commits unless find-bar input owns it. Branch and tag menus
support keys/mouse/scroll and contextual clipboard paste. Branch menus retain an
immutable snapshot so refresh cannot retarget an action. Commit buttons arm on
mouse-down and submit once on mouse-up inside. Leaving the panel clears capture.

Write completion triggers a fresh asynchronous status read; no optimistic row
toggle is published. Refresh/error never clears the draft. Successful commit only
clears the exact captured document/revision, preserving typing submitted afterward.
The shared editor supplies search, selection, history, clipboard and local completion
even with LSP configured. Successful checkout invalidates clean repository captures,
reloads active text/hex/image views and rescans/reindexes; newer explicit file opens
retain precedence and focus intent. Hidden clean caches bypass old session bytes.
Project search waits for checkout acknowledgement to avoid stale preview attachment.
History file lists are bounded to 32 expansions/20,000 cached paths.

Limits: checkout cannot be an atomic transaction across all worktree files, index
and refs. Late I/O errors explicitly report potential partial publication for
inspection. Crash-retained owned lock/staging data is not silently removed. Native
Windows/macOS lock fallback and terminal execution remain release qualification;
native calls have no hard cancellation/RSS guarantee. Commit drafts are not saved
across restarts, matching the baseline. G02 emits diff data; displaying/restoring
it is G03, not a claimed completed feature here. Full migration remains in progress.
