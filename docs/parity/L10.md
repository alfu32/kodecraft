# L10 — Other language adapters and heuristic fallback

Status: done. Source baseline: `7d3e5953ec2de75f2b5e9c44fb3e65549d39ec68`.
Summary: `feat(intelligence): preserve generic adapters and configurable fallback`.

`frontend/generic/` extracts actual AST declarations, nested scopes, imports,
identity-preserving occurrences, ownership/member relations and lexical facts.
The first and second original adapter batches cover C++, Go, JavaScript,
TypeScript/JSX/TSX, HTML, CSS, JSON, Python, PHP, Ruby, Bash and Swift. C and Kotlin
continue through their specialized native adapters. Real pinned node/field shapes
drive declaration names, including Bash `word`, Ruby constants, Swift patterns,
C++ declarators and TypeScript parameter/property paths. Name and occurrence
ranges slice exact raw UTF-8 text. Definition occurrences use declaration scope;
other bindings remain unresolved until the shared resolver applies scope rules.

`frontend/legacy/` loads the shipped 24-language definition catalog and aliases,
case-insensitive numbered regex captures, comment/string sanitization, declaration
priority and the source BRACE/INDENT/PAREN/REGEX/SQL/NONE block tracking modes.
Fallback facts retain explicit HEURISTIC confidence 0.50. ASCII masking preserves
raw byte positions across Unicode/CRLF; original snapshots remain untouched.
Unknown languages retain default patterns. Empty documents have a valid empty
file range rather than fabricating one source character. SearchRegex adds bounded
numbered capture access while preserving its existing Java pattern semantics.

DefinitionRegistry gives an explicit definitions file precedence over resource
roots. The L09 bootstrap supplies `KODE_CODEINTEL_PATH` as that explicit path.
Resource roots retain explicit > KODE_RS_HOME > eligible legacy KODE_HOME >
executable precedence, followed by the source's relative codeintel path and
compiled defaults. Overrides replace bundled definitions; primary language keys
win over aliases. Invalid catalogs use bundled definitions with diagnostics;
invalid patterns/capture indexes are reported, with default patterns when none
remain valid. Reading uses regular-file guards and a 1 MiB cap. Catalog URLs are
metadata, never automatic SDK/source downloads.

`SemanticAdapterSession` owns a document's mutable parser and reports Kotlin, C,
generic or heuristic capability. Grammar initialization/extraction failures yield
usable fallback plus a visible reason; cancellation propagates. Additional active
source parser registrations retain generic extraction plus configurable regex
definitions (for example SQL CREATE TABLE). AST declarations take precedence over
overlapping heuristic declarations. No Java process or language server is used.

The [capability inventory](L10-capabilities.json) records all 28 pinned variants.
Every dependency has an active source parser registration, except the additional
Markdown inline variant. TSX and OCaml interface use their qualified native
variants, improving on the source's shared TypeScript/OCaml parser choice.
Conservative AST extraction offers no Kotlin/C-level type guarantees. Some
markup/data grammars expose lexical/identifier/file-scope facts without semantic
declarations, consistent with their source adapters. Rust has no native grammar
in the source set and explicitly uses its shipped regex definitions.

Seven `tests/generic_adapters.rs` tests cover both original batches; 28 grammar
variants and 33 aliases (61 extraction/resolve/query cases); a synthetic TypeScript
path fixture with declarations/members/Unicode/shadowing; keyword exclusion;
unsupported/missing grammar fallback; external precedence and malformed catalogs;
numbered captures/lookbehind/Unicode/comment masking; unchanged reusable/fresh
parses; cancellation/depth limits; and empty documents. Corpus paths and developer
sessions are not used. L12 will combine the final active-language/persistence matrix.

Validation passed on stable Rust 1.99.0:

- `cargo test --offline -p kode-intelligence --test generic_adapters` — 7 passed.
- `cargo test --offline -p kode-core -p kode-intelligence -p kode-syntax --quiet -j2`
  — 127 passed.
- `cargo fmt --all --check` and `git diff --check`.
- `cargo check --offline --workspace --all-targets`.
- `cargo clippy --offline -p kode-core -p kode-intelligence -p kode-syntax --all-targets -- -D warnings`.

Extraction is bounded by source size, traversal depth, node/symbol/scope counts,
regex engine limits, output counts and cancellation/time checks. Fallback remains
approximate: no preprocessing, compiler validation, full generic substitution or
control-flow typing. No manual terminal check applies to this worker API; L09
attaches providers/status and bounds per-document adapter caches. Next: L11.
