## Shared APIs

Newtypes distinguish workspace generation, request, document and revision IDs;
UTF-8 bytes, Unicode scalars, logical lines, UTF-16 columns and terminal cells.
Half-open ranges reject reversed wire data and validate scalar boundaries against
text. Selections preserve direction. Job tags require exact freshness. Origins
distinguish actual paths from virtual owner/key/label identities.

Commands cover movement, edits/history, clipboard, search, folds, completion and
navigation. Domain errors distinguish stale edits, read-only capability, I/O,
parse/resource, process, Git, HTTP transport and SQLSTATE/vendor failures.
Immutable snapshots, completion replacement ranges, navigation/highlight DTOs and
provider/clipboard/document-I/O traits contain no terminal types. Test intelligence
providers are confined to tests. Prefix replacement preserves receiver separators.
