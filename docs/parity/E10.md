# E10 — Definitions, usages and hover preview

**Status:** done

Source baseline: `7d3e5953ec2de75f2b5e9c44fb3e65549d39ec68`.
Validated on Rust/Cargo 1.99.0 stable, Linux x86_64.

Navigation uses the shared intelligence/provider DTOs and injectable source/
highlight services. Ctrl-click falls back to a source identifier before semantic
coloring exists. Current, revision-checked declaration spans or definition hits
route declarations to all references; other clicks use source-compatible best
definition scoring. Actual provider calls, file reads, preview preparation and
syntax styling run through bounded workers. Native preview reading uses the
strict UTF-8/BOM-aware document service. The current unsaved document uses its
immutable captured buffer rather than a disk read.

Hover candidates retain document/revision/selection/token/deadline and fire at
500 ms from the host timer without another mouse move. Exact request/context
publication and dismissal prevent resurrection after changes, close, focus loss
or workspace switch. A completed popup retains its context for later invalidation.
Source errors remain typed in unavailable previews while target navigation and
controls remain available. Optional UTF-16 location metadata was added to the
shared target DTO for labels when source bytes are unavailable; old serialized
targets still deserialize with the field absent.

Definition previews deduplicate targets, show at most 24 declaration lines or the
identifier-line fallback, and paint precomputed widths/highlights without reads
or analysis. Multiple-target arrows and location links have exact clipped hit/
hover bounds; only the hovered arrow glyph is underlined. Pointer travel into
the popup stays with its owner. Escape dismisses; other keys route to the editor.
Missing source displays `source unavailable`; unknown line metadata displays `?`.

Usage popups preserve every reference, compact project-relative paths and
one-based line/column snippets. Up/Down/Page/Home/End/Enter, global wheel capture,
track clicks and anchored dragging keep all entries reachable. Track drag starts
from its newly clicked offset and release outside stops it. Other keys/paste
cannot edit the document. Padding is not a hover link and hover does not change
keyboard selection. Outside click dismisses immediately and is consumed before
any underlying selection. Tiny/edge layouts clip safely.

Nine tests cover UX-085–099: lexical Ctrl-click and declaration routing, fake
500 ms clock with no further mouse movement, multiple-target controls/hover/link,
current unsaved 24-line syntax-colored preview, missing source/outside dismissal,
all twelve reference entries and captured keys/wheel, track/release regressions,
stale/workspace/tiny behavior and definition-only editing, compact paths, actual
provider worker publication and native BOM/CRLF preview reading without changing
file bytes. Source regression assertions were replayed through editor input.
Actual intelligence/LSP and workspace navigation composition remain L09/P03/W05;
E12 attaches these widgets to the reusable host interface.
