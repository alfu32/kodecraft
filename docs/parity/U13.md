## Verified

- The Rust SQL runtime identifies Oracle from the selected JDBC driver and removes a trailing SQL delimiter only from the payload sent to JDBC. The editor document remains unchanged. Oracle `BEGIN` / `DECLARE` blocks and package, procedure, function, trigger, and type bodies retain their internal semicolons.
- Unit coverage verifies Oracle delimiter handling, comments, PL/SQL preservation, driver identification, and unchanged non-Oracle behavior.
- The live Oracle TUI replay uses two separately opened JDBC sessions. It creates a package and table on the second session, refreshes the explorer on the first session without reconnecting, and confirms the newly committed objects appear in the tree. It opens the package source as a read-only document.
- The live Oracle replay refreshes again while the first refresh is still loading; the resulting tree accepts only the current request and contains the external DDL.
- The same live Oracle replay executes `SELECT 1 FROM DUAL;` and `BEGIN NULL; END;` through the SQL editor, verifies successful completion and the driver payload, and checks that the editor text is preserved.
- Script execution sends independent statements sequentially, keeps every statement's result set/update count in the combined preview, strips statement delimiters from Oracle SQL payloads, preserves PL/SQL blocks as a single unit, and accepts SQL*Plus slash-only separators. The live Oracle replay creates two table rows using SQL plus an anonymous block, then executes a final count query and verifies both rows; the H2 TUI replay confirms two separate `SELECT` results remain visible together.
- Error handling stops a script at its first failed statement, retains the database error, and does not run later statements. A live Oracle script with a deliberately missing table is followed by a count query proving the later insert did not execute; the H2-backed replay checks the same behavior.
- A live Oracle cancellation returns a cancelled execution for Oracle vendor error 1013 while retaining the diagnostic. The same replay verifies transaction rollback removes an uncommitted insert and commit preserves a later insert.
- A separate H2-backed TUI integration test exercises the Oracle adapter selection and verifies the submitted payload and editor contents.
