# U06 — Word selection with double-click and Alt+double-click

Status: done

M005 is implemented in the shared editor. Two completed left clicks within
350 ms select the Unicode word/segment under the pointer; Alt+double-click adds
it, with a cursor at its end. A pair requires the same cell/source, modifiers,
document revision, geometry/scroll/folds and caret context. Drag, resize, focus
loss and intervening keys break it. Each pair is consumed once: a third click
starts a new pair, rather than switching to line selection.

Alt gestures retain the complete state before the first U04 toggle. The first
click may have removed a cursor already under the pointer; accepting the word
result starts from that earlier state, adds the word and normalizes the set.
The first click's actual selection remains visible while analysis is pending.
Canceling or superseding a request never rolls back a newer selection and never
leaves temporary duplicate cursors. Plain double-click produces one selection.
Added word selections participate in the existing one-transaction edit/undo path.

`VisualLayout::cell_source` identifies the scalar painted under a click, including
inside a tab, combining mark, wide character or emoji escape. It is distinct from
ordinary caret placement's ceiling boundary. The narrow real-terminal fixture
found and fixed a fold-prefix end that mapped to column zero when its following
scalar was clipped. The visible prefix boundary now retains its proper caret.
Fold ellipses retain their existing fold-toggle behavior.

Boundary analysis uses pinned unicode-segmentation **1.13.3**, UAX #29. Accented,
combining, underscore, contraction, Arabic/Hebrew/Cyrillic and numeric words have
exact source byte ranges. CJK ideographs are individual Unicode word segments;
whitespace and punctuation follow the same segment rules. Blank positions at or
beyond a logical line's content remain carets; selection never includes CR/LF or
crosses a logical line. Visual wrapping does not split the underlying word.

Line materialization and segmentation run on the bounded blocking scheduler,
using an immutable snapshot. Local/scheduler cancellation is checked during rope
chunk copying and between segments; the library's individual segment advance is
not forcibly interrupted. Publication requires the current workspace, view,
request, document/revision, full caret set, actual focus and geometry/scroll/folds.
Late results cannot consume newer work. Detach/drop, quit and workspace departure
cancel pending pointer jobs before critical session work. Accepted asynchronous
selection marks workspace state changed so autosave can retain it.

The host supplies the same injectable clock used for navigation, with a monotonic
default for standalone inputs. Existing single-click fixtures now use explicit
clock advancement or separate real clicks beyond the double-click interval;
production recognition is unchanged to accommodate tests.

  Java/H2 cases left disabled in this command. They are not claimed as run here.
- Three word-boundary tests cover every scalar in named multilingual words,
  whitespace/punctuation/CJK/emoji, CRLF/empty/EOF and a 1.2 MiB combining-word
  fixture, including cancellation during rope copying and unchanged document state.
- Nine fake-clock input cases cover the exact timing boundary, completed releases,
  modifiers, repeated pairs, Alt restoration, reverse/overlapping existing sets,
  tab/escape interiors, wraps/folds, tiny panes, read-only mutation guards and stale
  result/context/drop/cancellation behavior. Old results leave newer requests intact.
- Shared-host integration applies both gestures in file/project-search, SQL, REST
  body/headers/environment and response/raw/historical hosts. Copy produces exact
  word text; edits/undo retain every selection and read-only hosts reject changes.
- Actual runtime coverage publishes a real word worker, checks the session
  sequence, and confirms quit cancels unsubmitted work while retaining physical
  file bytes. The existing 12 multi-cursor PTYs remain passing.
- Format, affected check, all-target Clippy with warnings denied and CLI build pass.
