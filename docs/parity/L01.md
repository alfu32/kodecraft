# L01 — Semantic facts, identifiers and immutable snapshots

Status: done  
Source baseline: `7d3e5953ec2de75f2b5e9c44fb3e65549d39ec68`  
Compiler: stable `rustc 1.99.0 (b940084d7 2026-09-28)`.

The native semantic model now includes every source symbol/scope/occurrence,
lexical, relation/dependency, import, unresolved type, expression type and hint
record, all TypeRef variants, confidence provenance and knowledge levels. File,
symbol, scope, type and occurrence identities are distinct signed 64-bit types.
SourceRange reuses validated half-open UTF-8 TextRange. Confidence rejects
non-finite/out-of-range values in constructors and deserialization.

Stable IDs preserve source FNV-1a bit patterns and signed decimal components, with
byte offsets explicit in Rust constructors. Three fixtures compiled from the
frozen Kotlin model confirm exact identities, including emoji/non-ASCII prefixes.
The fixture labels those inputs UTF8_BYTES and confirms the legacy UTF-16 offset
would produce a different declaration ID. Native semantic persistence is therefore
not advertised as compatible with old UTF-16-offset cache identities.

The exported surface hash retains declaration identities, names/kinds/visibility,
type/initializer hints and imports while excluding local bodies and declaration
end ranges. Moving a declaration changes its identity/surface, as in the source.

SemanticSnapshot prepares immutable query tables before publication, indexing
file/path/symbol/scope lookup, occurrences/references, lexical spans, expression
types, relations, members, visibility and dependencies. Named/generic/nullable/
union member queries preserve local overrides and traverse inheritance/alias
relations with cycle guards. Visible symbols respect inner-scope shadowing,
declaration order and private/protected accessibility. Interval tables use prefix
maximum ends so long nested spans are not lost behind shorter non-overlapping
records, correcting a weakness in the source's backward range walk.

Identical stable records collapse; conflicting duplicate identities fail visibly.
Scope cycles, foreign file records and dangling scope/owner/relation/dependency
links are rejected. Duplicate expressions retain the strongest confidence and
exclude empty ranges. Source validation separately checks all fact ranges against
the actual UTF-8 text. The immutable resolved project remains separate from its
original extraction deltas; this layer does not fabricate resolution facts.

SnapshotPublisher swaps prepared snapshots under a short lock, requires increasing
revisions and returns the old snapshot for release outside the lock. Readers keep
old Arc-backed tables intact during later publication. Persistence/coordinator
cards must call publication only after their successful transaction and tag checks.
