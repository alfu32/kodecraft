# E11 — Highlight overlays and edit remapping

Task: E11. Status: done.
Source baseline: `7d3e5953ec2de75f2b5e9c44fb3e65549d39ec68`; reference tree clean.

Implemented `kode-tui/src/editor/overlays/{mod,cache,remap,worker}.rs`, integrated
the shared editor host, main/project-search runtime, definition previews, renderer
and repaint watch channel. Public contracts are recorded in CONTRACTS.md.
Source: HighlightEdits.kt, CodeEditorView.kt's paint/composition helpers,
HighlightEditsTest and SemanticHighlightingTest. L02/L09 APIs are real prerequisites.

Lexical/semantic reports run on existing bounded F03 workers. Reused parser
sessions stay off the UI thread. Reports capture document/revision/coverage and
pass both exact-request and native query epoch/index revision gates. A stale
query reschedules current paint. Dependent-file publication invalidates the
unchanged editor. Worker notifications directly wake the event loop; no keypress
or terminal input deadline is needed to publish paint. A 16 ms timer remains for
input, hover/drag, watch/debounce and the existing application heartbeat.

Paint composition uses an endpoint sweep and disjoint byte segments. Glyphs and
punctuation still come exclusively from the existing layout/source map. The order
is body → lexical → semantic → warning background → hover underline → search →
active search → transient → tabs → selection → cursor. This deliberately keeps
warnings visible above code-intelligence backgrounds. Fold summaries use the same
prepared paint. Explicit theme properties preserve declaration/usage decorations
when semantic kinds supply foreground colors. Grammar/fallback status precedes
long paths in the header. Native declaration spans now drive Ctrl-click declaration
versus usage routing, and captured-source definition previews receive native styles.

Cached spans shift immediately with core right-to-left transaction deltas; touched
spans and tokens joined at either boundary disappear. Undo/shared-view edits use a
UTF-8 scalar-safe contiguous rope diff. Successive edits operate on the immediately
previous snapshot. Neither route flattens the document on the input/paint thread.
Ready empty semantic reports clear paint; provider failures retain only remapped
paint and expose a note. Limits/fallbacks are explicit in CONTRACTS.md.
