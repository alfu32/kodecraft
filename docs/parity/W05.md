# W05 — CLI targets and workspace application shell

Status: done  
Source baseline: `7d3e5953ec2de75f2b5e9c44fb3e65549d39ec68`  
Compiler: `rustc 1.99.0 (b940084d7 2026-09-28)`, latest installed stable.

The executable now launches the terminal application for a file or folder. An
explicit file wins over restored session focus; no target prints help. Missing
and special targets report errors. `--resources` and the established environment
resource precedence load MIME rules and styles before terminal acquisition.
Application logs use the platform's bounded file logger, including panic cleanup.

The application thread owns the Files/Project/Help sidebar, splitter, editor,
focus, recents, project search and folder/name/rescan dialogs. Typed commands
connect these views to bounded workers for loading, saving, clipboard, scans,
search, folding, completion, navigation, file actions and session persistence.
Project mutations serialize so overlapping root/exclusion changes cannot erase
one another. Scan batches use an eight-slot channel with cooperative cancellation;
progress is coalesced independently from reliable completions. Optional feature
services attach through editor hosts and typed application work.

Workspace switching flushes captured view state and pending critical writes,
cancels interactive work, joins workers, disposes the watcher, advances generation,
and restores the new workspace. Queued terminal input from the former workspace
is discarded. A refused session write leaves the current workspace open. A broken
terminal triggers flush and service cleanup; if session persistence conflicts,
dirty buffers get separate restricted recovery files before services are joined.

Reopening an owned document reuses its current text/history, including when its
file has disappeared. Definition navigation retains document identity and byte or
UTF-16 location, restores editor focus and centers the target with viewport clamps.
Legacy imports also preserve clean CRLF history through the first native capture;
subsequent restores do not perform legacy newline conversion again.
