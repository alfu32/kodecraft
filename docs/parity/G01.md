# G01 — Repository discovery and read operations

Task: G01. Status: done.
Source baseline: `7d3e5953ec2de75f2b5e9c44fb3e65549d39ec68`; reference tree clean.

Read IGitService.kt/JGitService, GitPanelView.kt's refresh/error paths and both
JGitServiceTest/GitPanelViewTest regressions. Implemented owned models, discovery,
status and typed read jobs in `kode-git/src/{model,repository,status,read}.rs` and
`read/content.rs`; reusable read-panel reducer/rendering in
`kode-tui/src/panels/git/read.rs`. G02 composes that read panel into the application
with write controls/commit editor; G03 owns interactive diff rendering/restoration.

Selected and inspected actual git2 0.21.0 sources for repository discovery, status
options, ODB headers, object peeling, history/diffs and similarity. Vendored
libgit2-sys 0.18.8+1.9.7 is pinned in Cargo.lock; local operations enable no SSH/
HTTPS transport, JGit or JVM. Application code remains safe Rust. Native handles
open/drop inside F03 blocking jobs and never enter interactive state or paint.

Discovery supports nested folders/file paths, linked worktrees and bare repos.
Missing repositories and malformed local metadata are distinct. HEAD reports
unborn, full branch reference/name or detached commit. Branch names preserve their
hierarchy instead of the source's ambiguous last segment. Status preserves separate
staged/unstaged rows for one path and reports added/modified/deleted/untracked/
type-changed/unreadable/conflicted states. Conflict codes come from actual merge
stages. Status renames retain source-compatible add/delete rows; status does not
load explicit blob content or enable similarity detection. Index refresh/stat
updates are disabled. Repository content/mtime snapshots prove reads do not write.

History reports commit identity, author/time/offset/message/parents and selected
tag. Annotated tag choice matches Kotlin's numeric scoring, including overflowed
digit runs, ten-bit slots, signed shifts and first-tie ordering. Lightweight tags
remain available in raw listing and do not change source-compatible history labels.
Root commit files compare against an empty tree; other file lists compare the first
parent, detect exact renames and bounded edited renames, and retain deleted paths.
Content requests resolve stored commit/index bytes separately from worktree bytes.
Git clean filters are respected as repository data, not silently re-applied by
the reader. Missing/binary/oversized/symlink/submodule states are explicit.

Explicit blob reads check ODB headers before loading, with bounded regular-file
worktree reads and concurrent-change checks. Leaf symlinks return their value,
known parent escapes and Git metadata/absolute/parent paths are rejected, and Unix
non-UTF-8 path identity survives. Oversized blobs return size/classification with
no fake empty text. Status survives the original low-threshold large-object case.
Refresh reports retain section errors alongside available data. UI acknowledgement
preserves selection/earlier rows on whole-job error, rejects stale owners/workspaces,
shows errors and limits, and never reads a repository during rendering.
