# U11 — Connection-type JDBC URL template dropdown

Status: done

M007 is implemented beside the datasource dialog's JDBC URL input. Click
**[Templates]** (compact **[v]** in a very narrow field), or press **Down** while
editing the URL. The label advertises the key. Both routes use the existing
connection-type catalog and asynchronously loaded, credential-filtered recent
URLs. Choosing a template updates only the URL and restores editing focus;
placeholders remain editable. Escape cancels the menu without changing typed
text. Canceling the datasource dialog leaves the stored connection unchanged.

Changing connection type preserves a nonempty manual URL and rebuilds choices
for the new type. Late recent-URL results preserve the highlighted template's
value as rows are inserted, avoiding an unexpected selection change. Unrelated
connection types and credential-bearing recent URLs are not displayed. An empty
catalog has an explicit manual-entry/escape message.

The URL field and button have separate bounded hit areas, including the existing
single-row tiny-dialog fallback. Text editing and caret scrolling use the reduced
field area; the button cannot move the cursor into a different input.

Validation: **22 tests pass**: database_connection_dialog (9), database_app (10,
including two explicitly enabled real Java/H2 panel and SQL tests), and
database_services (3). New cases cover PostgreSQL, MySQL, Oracle, SQL Server and
H2, keyboard/mouse selection, type switches with manual URLs, cancel/focus,
editable template text, recent-result ordering and credential filtering. The
existing exhaustive tiny-geometry/password masking cases remain passing.
All-target kode-tui clippy with `-D warnings`, debug build and format pass.

[Six real PTY cases](U11-pty.json) exercise H2/PostgreSQL/Oracle at 100×34 and
60×18: type switching, retained manual input, template button, popup cancel,
keyboard/mouse selection, exact saved URL/type, subsequent canceled edits,
unchanged editor bytes and terminal restoration. These template fixtures do not
contact any database; only the separate H2 integration tests make real connections.
