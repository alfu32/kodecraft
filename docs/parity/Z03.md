# Z03 — Reproducible build and distribution

Status: in-progress

The Linux x86_64 GNU archive now includes the executable/resources, separate JDBC
helper, full dependency legal texts, launcher sources and a relocated standalone
ttyd/library bundle. It contains **no JVM**. Minimum tested glibc is **2.39**.
[Archive evidence](Z03-archive.json) records **984 files**, **32,813,172 compressed
bytes** and matching independent assemblies of the same inputs:

`e16bc9d3668e9de49285b5da05f68a47d1eebd039b7fc173bf38c880b1653f59`

Legal collection covers **405 Linux Rust build/runtime dependencies**, **30 pinned
Java runtime libraries**, native components and **18 ttyd browser dependencies**.
Original copyright/developer/POM declarations and upstream source/hash provenance
are retained. The helper's full runtime closure and hashes are locked; its two
builds match. [All 64 helper tests and rebuild evidence](Z03-helper-build.json)
are qualified locally. Native libraries use relative RPATH; libuv is built into
checksummed libwebsockets/ttyd to avoid a nonrelocatable event-plugin search path.

- [Four archive/clean-OS cases](Z03-archive.json): exact manifests/modes/legal
  files, developer path absence, shell and Linux PowerShell launchers, no-Java
  PTY core, real packaged-helper H2 SQL, and browser save/disconnect in an
  unprivileged, read-only pinned Ubuntu container with no Java or CA store.
- [Five packaged browser cases over SSH](Z03-browser.json): all eight panel
  shortcuts, editing, browser clipboard, reconnect, streaming REST cancellation,
  actual H2 SQL and dirty persistence/helper reaping. Adjacent executables/helper
  are used, with no developer library path. Evidence matches the archive manifest.
- [Three integrity rejection cases](Z03-integrity.json): corrupt legal text,
  corrupt native library and stale helper each fail for the expected reason,
  without publishing an archive.

The clean-image fixture exposed eager LSP TLS client construction blocking editor
startup without CA certificates. Initialization is now deferred to explicit
installation on the existing blocking worker; failures can be retried after system
TLS setup is repaired. TLS validation remains enabled. Seven LSP installer tests,
19 application-runtime tests, affected all-target clippy, format, credits and task
ledger checks pass. Docker bridge routing was unavailable locally; the clean-OS
browser case uses loopback host networking and changes no host network settings.

**Remaining:** actual AppImage/Snap formats, full CI/release orchestration and
publication, independent Rust/native build reproducibility, complete native
compiler/package provenance, and final installer/platform qualification. Windows
launcher execution and non-Linux-x86_64 artifacts are unqualified. No remote CI or
release upload has run. Full scope and exact continuation commands are in the
[handoff](../migration/Z03-INTEGRATION.md) and
[distribution guide](../../packaging/README.md).
