# E05 — Visual layout and editor cell rendering

**Status:** done

Source baseline: `7d3e5953ec2de75f2b5e9c44fb3e65549d39ec68`.
Validated on Rust/Cargo 1.99.0 stable, Linux x86_64.

The editor uses a revision/width/fold keyed layout cache, rope line iterators,
scalar byte ranges, whole glyph wrap runs, and a shared forward/inverse map.
Rendering paints only visible prepared rows; no file reads, parsing or service
calls occur in paint. Header path/dirty/MIME/language/grammar, line numbers,
selection, overlays, tab styles and focused caret have explicit clipped geometry.
Search, folds, minimap and popup owners can use the same geometry and source map.

The compatibility fixture verifies fixed four-cell `|-->` tabs and control,
wide, combining and supplementary escapes. Unicode category tables are pinned
to Unicode 15.0.0 to match Java 21. Fitting tab/escape glyphs remain atomic when
wrapping; oversized glyphs clip without splitting a raw scalar. Clicks inside
escapes map to valid scalar boundaries using the source's ceiling rule.

Intentional corrections: escape enclosing marks and terminal-wide BMP emoji
missed by the source's width helper; preserve the last punctuation cell when a
focused caret is exactly at a full wrap/EOF boundary. Owned editor, dialog and
field surfaces clear stale/underlying cells before painting.

Seven rendering tests cover UX-033–035/040–042/048 at the rendering boundary:
compatibility display, source wrapped-tab page coordinates, scalar hit-map
round trips, exact header/gutter/styles, wrap/EOF punctuation, cache/fold
invalidation, and zero/tiny/search-height geometries. Eight widget tests pass,
including drawing dialogs over existing text. Input integration belongs to E06;
fold discovery, collapsed summaries and Braille minimap drawing belong to E08.

Passed: all 67 workspace tests, `cargo fmt --all --check`, and
`cargo clippy --offline --workspace --all-targets -- -D warnings`.
