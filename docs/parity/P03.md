# P03 — Editor enrichment and provider fallback

Task: P03. Status: done.
Source baseline: `7d3e5953ec2de75f2b5e9c44fb3e65549d39ec68`; reference tree clean.

Read LspEditorIntelligence.kt, CompositeEditorIntelligenceService in
EditorIntelligence.kt, LspService.kt language selection and CodeEditorView.kt's
document hooks. The executable source uses non-empty primary results, otherwise
native fallback. Its diagnostics/document-symbol/prepare-rename methods are empty
defaults; they are not implemented editor functionality. No proposed merge,
refactoring or diagnostic UI is claimed as parity evidence.

Implemented `kode-lsp/src/provider.rs` and bounded coordinate/item conversion in
`provider/convert.rs`. Application composition lives in app/runtime/lsp.rs and the
existing intelligence/query worker paths. File/search hosts and workspace-owned
file documents supply immutable rope captures without filesystem work or flattening
on the UI thread. A coalesced F03 worker starts the first matching local server
when a file host attaches, preserving source behavior without automatic downloads.
Explicit stop/crash does not cause an immediate retry loop. Language aliases use
the same mapping for discovery selection, running selection and protocol documents.

Exact captures synchronize before definitions/references/completion queries,
including other selected unsaved buffers. Current non-empty primary results win;
empty/error/unsupported/stale replies use the native facade. Lists are not merged.
Existing host suggestions still precede the composed provider. Highlighting and
delayed definition previews retain native styling. Plain insertion and prefix
text edits preserve receivers/suffixes; unsupported snippet/additional-edit/command/
insert-replace items are excluded, allowing fallback if nothing usable remains.
Server ordering/details, stable deduplication and the 50-entry limit are retained.

Locations and LocationLinks map negotiated UTF-8/16/32 coordinates through exact
current captures or bounded regular-file reads, retaining declaration/selection
ranges, editor identities and portable UTF-16 navigation locations. Unsaved targets
must have matching server stamps. Non-file URIs are excluded. Missing UTF-16 source
retains its location and source-unavailable state; unreadable UTF-8/32 targets do
not invent byte coordinates. A preview whose missing source becomes available maps
its saved location before drawing. Capture/target bounds are recorded in CONTRACTS.

Source changes cancel requests. Worker validation checks source epoch, document
identity/revision, selected server and replica stamp before/after conversion.
Publication checks source epoch/registry revision again, covering changes after a
worker queues its reply. Owner, focus, selection, context and workspace gates stay
active. Fully primary results survive unrelated native-index publication; mixed
and fallback results retain the native epoch/index gate. Captures are observed
before stamping new requests, and synchronously installed cached hosts receive
providers before the next input event. These ordering fixes were driven by real
app tests, including immediate navigation after reopening a cached file.

Open/change/rename/close flow through the actor-owned replicas. Physical saves send
actual saved bytes only after successful disk persistence; LSP failure cannot
invalidate a successful physical save. A late save of an older revision sends
didSave without reverting a newer unsaved didChange replica. Workspace disposal
cancels enrichment queries before draining workers and reaping language servers.
