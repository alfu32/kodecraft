# U10 — Panel shortcuts follow visual tab order

Status: done

B007 is implemented and qualified in native terminals and the SSH browser workflow.
Alt+1..8 follows the displayed order: **Files, Project, Git, Database, REST, About,
Settings, Help**. The shared command catalog, generated Help, README, SQL recovery
hint and existing terminal/browser fixtures use this mapping. The horizontal tab
widget keeps the selected panel visible when the header overflows.

Global routing computes the semantic destination before Git cleanup. Alt+3 retains
an open Git diff; Alt+5 leaves it for REST and restores the underlying editor.
Selection and focus use the same panel owners as mouse clicks. Normal editor
focus does not consume a panel chord or insert its digit into the document.
Existing modal/input priority and file/project find mappings remain intact.

Evidence:

- The application test covers **all 64 source/destination pairs at each of 60 and
  100 columns**. Each target starts from editor focus, checks the selected visual
  index and actual focus owner, presses F6 and clicks the same visible header,
  then verifies the original editor buffer and physical file are unchanged.
- [Four actual PTYs](U10-pty.json), generated by
  `scripts/test-panel-shortcuts-terminal.py`, deliver all eight digits using both
  **escape-prefix and CSI-u encodings at 60/100 columns**. Each checks the visible
  target content, F6/editor focus and matching mouse target; file/session text stays
  unchanged and terminal modes restore.
- **37 actual terminal cases pass**: four dedicated shortcuts, five operational,
  three Git, two Git diff, three database, four SQL, two diagnostics, four REST,
  four REST runner, two native settings, two LSP settings and two LSP lifecycle.
  The Git diff cases explicitly retain the viewer on Alt+3, reject edits and leave
  for REST on Alt+5 while preserving exact CRLF/restored hunk/index/HEAD state.
- [Actual Chrome/ttyd browser evidence](U10-browser.json) delivers all eight
  Alt+number keys from editor focus at wide/narrow browser sizes over an isolated
  OpenSSH tunnel. The physical file remains unchanged. All **five browser cases**
  pass, including browser clipboard/save/resize/disconnect/reconnect, streaming
  and real Java/H2 SQL. The fixture restores editor focus/caret before continuing
  its existing clipboard checks.
- Full `cargo test -p kode-tui` passes after updating the JDBC fixture's old key.
  The three explicit JDBC qualification cases also pass, including real helper
  crash/workspace switching, and both normally ignored real H2 application tests
  pass with the new Database chord.
- All-target TUI clippy with `-D warnings`, workspace all-target check, formatting,
  521 locked credits and diff checks pass. Generated task ledgers are reconciled
  at completion; both task checks pass.

Historical parity reports record earlier shortcut checkpoints. B007/U10 is the
current mapping; U01 remains Ctrl+F file find and Alt+F project search.
