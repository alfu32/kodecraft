# V01 — MIME/language detection and routing

**Status:** done

Source baseline: `7d3e5953ec2de75f2b5e9c44fb3e65549d39ec68`.
Validated on Rust/Cargo 1.99.0 stable, Linux x86_64.

`kode-workspace/src/mime/` uses the F02 `resources/mime-types.json` compiled table
and supports validated external tables, extension/filename overrides, immutable
worker classification, category and explicit viewer routing. All 281 source rows
retain category/language/MIME/extension spelling and last-duplicate-wins semantics.
The [sample matrix](../../fixtures/mime/sample-matrix.json) records all 225 tracked
source sample filenames using the actual Kotlin last-suffix algorithm; untracked
metadata and sample contents are not imported. Systemd's 20 suffixes, C+ `.cp`, C
headers and C++ header variants have explicit regression coverage.

Shell shebangs precede filename/extension mappings, including BOM, env assignments/
options, CRLF and the source's eleven shell interpreter names. Exact conventional
filenames (Dockerfile, Makefile/GNUmakefile, CMakeLists.txt, CODEOWNERS, dotfiles)
can choose curated syntax before ordinary signatures. The original last-suffix
behavior for `.blade.php` stays intact. Source partial PNG/JPEG/GIF/PDF/ZIP/gzip/
MP4/MP3 signatures precede infer 0.22.0's additional signatures. Unknown suffixes
use deterministic mime_guess 2.0.5 after content signatures, replacing variable
JVM platform probes without overriding explicit Kode mappings.

Default reads are 3072 bytes plus one byte to detect a sample cut; the maximum
configurable bound is 64 KiB, and zero selects the source's 4096-byte file fallback.
Regular-file validation rejects directories/devices/pipes before opening a sample.
Read failures, missing files and cancellation return visible typed errors. Valid
Unicode text is recognized without the source's ASCII-only 90% bias; NUL and
invalid UTF-8 remain binary. Generic XML declarations are classified as text,
correcting the source's blanket SVG detection. UTF-8 scalars cut by the bounded
sample do not make ordinary Unicode files falsely binary.

`FileClassification` returns detected MIME/language/category/source and a viewer.
Text uses Code, binary/unknown use Hex. Image requires a decoder capability
explicitly supplied by the V03 service; an image MIME does not claim a working
decoder. Unsupported image hints retain a message and permit byte inspection.
Known text whose full decode fails can switch to Hex with the original error.
The source's `.svg` text-table classification remains Code; signature-only SVG
can route Image when that decoder is enabled.

Six focused regressions cover every original detector test, the complete sample
matrix and effective source table, precedence, all source signatures, shell
variants, overrides, Unicode/binary/XML corrections, bounded/missing/special/
unreadable inputs, decoder capabilities, decode failure and an actual bounded
classification worker. Passed: all **154 workspace tests**, workspace check,
format check and workspace all-target Clippy with warnings denied. The fixture
manifest now records 37 synthetic/licensed cases. Actual image decoding and native
format qualification remain V03/Z04; shell error presentation is W05.
