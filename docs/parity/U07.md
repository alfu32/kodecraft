# U07 — File-tree pickers for filesystem path fields

Status: done. The implementation covers and qualifies every row of the
[source-backed inventory](../migration/U07-INVENTORY.md).

The shared chooser supports existing files, new save filenames, directories and
existing file/directory paths. REST import/export, SQL Save, Local JAR(s), binary
REST bodies and multipart file rows have adjacent buttons and Alt+P. Compact
buttons and focused-control layouts retain keyboard/mouse access in small views.
Workspace, source-root and scan-exclusion selectors use the same widget.

Preparation, directory/tree loading and validation execute on workers. Browsing
outside the workspace does not load another project's settings. File selection
does not write content: import, export, SQL save, datasource save, request Send
and project configuration retain their own guards. F4 selects the parent for
navigation; Go opens the typed path's location, Tab cycles controls, Enter
activates the focused control, and Escape cancels with the original field and
focus intact. Ctrl+C/X/V and bracketed paste use the existing text-field and
clipboard worker paths.

Local JAR selection replaces the native classpath component at the caret,
preserving other entries and unrelated datasource values. Separator-containing
filenames and paths exceeding helper/field limits fail without splitting or
truncating the path. SQL and JAR capture preserve exact filename whitespace.
Multipart file selection replaces a scalar source or appends to an existing JSON
source array; type, other sources and unknown row metadata survive submission.
The picker is disabled for ordinary text rows. Binary choice changes the actual
`body.file.src` consumed by request resolution.

Workspace, modal nonce, field/caret/focus, driver and REST item/type/model proofs
reject stale preparation and selection. Each tree/validation/navigation/clipboard
reply has an exact request gate. Closing, focus loss, cancellation, replacing an
owner and workspace departure cannot publish into a new chooser. Slow chooser
workers retain their scheduler owner. Tree refreshes preserve typed/native
selection, skip concurrently removed siblings, and never silently replace an
unavailable selection with the filesystem root. Non-UTF-8 paths fail explicitly.

Reproduce the ordinary checks with stable Rust and an isolated target directory:

```sh
cargo +stable fmt --all -- --check
cargo +stable test -p kode-core -p kode-workspace -p kode-tui
cargo +stable clippy -p kode-core -p kode-workspace -p kode-tui --all-targets -- -D warnings
cargo +stable build -p kode
python3 scripts/test-path-picker-terminal.py --binary /path/to/kode
```

For explicit JDBC qualification, set `KODE_TEST_JDBC_HELPER` to the built Java 21
helper and `KODE_TEST_H2_JAR` to H2 2.2.224, then run:

```sh
cargo +stable test -p kode-tui --test database_app --test jdbc_qualification -- --include-ignored
```

This is local Linux UI/operation qualification. Z03 retains native Windows/macOS
and both CPU architecture qualification after U01–U12, including the authorized
Windows testing host and project directory in the
[artifact matrix](../migration/Z03-ARTIFACT-MATRIX.md).
