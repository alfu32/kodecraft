# L09 — Background index coordinator and editor facade

Status: done. Source baseline: `7d3e5953ec2de75f2b5e9c44fb3e65549d39ec68`.
Summary: `feat(intelligence): wire bounded native indexing and editor queries`.

`service/{mod,work}.rs` composes configured W01 scanning, V01 detection, guarded
UTF-8 source loading, L03/L04/L10 extraction, L08 incremental resolution, L05
SQLite persistence and atomic publication. It adds kode-workspace as a dependency
without a reverse dependency or UI types. The main-thread coordinator only captures
Ropes, coalesces requests and gates completions. Expensive work uses the existing
F03 bounded application scheduler; SQLite retains its dedicated worker.

Live input coalesces by physical/virtual file identity with document ID/revision
and a 200 ms debounce, independent of raw disk revision zero. At most 128 live
updates queue; capture/parser caches retain at most 32 entries / 64 MiB source text.
Prepared work must match the current source epoch, checked again at actual write
submission. Accepted writes drain as critical work. Newer edits remain queued even
if an older already-accepted transaction finishes. Old query readers remain stable.
Status distinguishes queued, scanning, extraction, resolution, persistence, ready,
error, cancellation and shutdown, with bounded fallback/partial-inference notes.

Rescan removes missing files only after a complete source traversal; failed reads
and incomplete scans preserve previous good facts and report the problem. Rebuild
resets frontend sessions and requalifies files; clear removes native index facts.
Startup requalifies persisted extraction with current override resources even if
source bytes are unchanged. Incompatible/foreign/unavailable cache errors select
a visible memory fallback without overwriting foreign data or starting Java.

`facade.rs` implements native definitions, references, completions and highlights.
Identity-linked navigation retains declaration ranges, language, kind, document
ownership and explicit missing-source metadata. Virtual identities depend on
serialized owner/key rather than display labels. Queries include captured unsaved
buffers in a private snapshot when required and never publish it. Preview readers
prefer current captured source over disk. `tokens.rs` exposes source-compatible
lexical/semantic classes, declaration/usage/method/field scopes and ranged queries.
Token reports include document stamp, dependency generation and index revision.

The real application registers providers in file and project-search editor hosts.
Completion/navigation results are gated against document/request/workspace and
index/source epochs. Affected-file publications dismiss stale completion/preview
state; E11 owns the subsequent highlight/style composition and edit remapping.
The footer exposes index phase, revision, counts and notes. Project `r`, `b`, `c`
actions rescan/rebuild/clear. Abort cancels both scan/index preparation, retaining
independent live edits; its modal waits for acknowledgement. Workspace disposal
stops providers, joins jobs, drains accepted writes and awaits SQLite shutdown.

External source changes use a non-consuming watcher revision plus debounce and
fallback polling. Index/session/build metadata do not advance that revision, so
SQLite writes cannot retrigger indexing. Clear does not immediately refill itself
through polling. Real disk refresh testing exposed equal-revision tree reuse:
fresh disk captures now have fresh document IDs, and the parser compares raw source
bytes before reusing an equal-revision tree. Editor IDs/revisions still permit
incremental reuse. The regression compares refreshed/fresh trees and old readers.

Ten `kode-intelligence/tests/service.rs` tests exercise the actual F03 scheduler,
complete scan-to-publication flow, editor compatibility queries, debounce/document
identity races, stale preparation and submission, accepted transaction draining
under an actual SQLite write lock, other unsaved buffers, tokens/CRLF/Unicode,
navigation/references/missing source, clear/rebuild/remove/restart, cancellation,
foreign-cache preservation, changed external patterns and virtual identity.
Three native cases in `kode-tui/tests/app_runtime.rs` exercise actual Ctrl+Space,
insertion, Ctrl-click navigation, workspace switch/provider shutdown, external disk
refresh, clear/rebuild, no SQLite watcher loop and acknowledged modal cancellation.
They supplement the existing shell/editor/ownership regressions.
