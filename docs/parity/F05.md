# F05 — Common widgets, style mapping, layout and focus

**Status:** done

Source baseline: `7d3e5953ec2de75f2b5e9c44fb3e65549d39ec68`.
Toolchain tested: Rust/Cargo 1.99.0 stable, Linux x86_64.

Changed paths: TUI `theme/`, `layout/`, `focus/`, `widgets/`, widget integration
tests and explicit Unicode-width dependency. Source style merging, colors,
overflowing tabs, modal fields/buttons, sliders and focus dispatch were audited.

The compatibility theme loader retains exact style IDs, ancestor selector spelling,
supported geometry/colors/decorations and unknown extension properties. Later
rules override defaults while deep copies keep extensions independent. Decorations
replace prior decorations instead of accidentally retaining an old bold flag.

Common controls include clipped horizontal/vertical tabs, captured draggable pane
splitters, scrollbars, sliders, bounded Unicode text fields, clipboard action
boundaries, buttons and modal dialogs. Lists/tables/borders use Ratatui widgets.
Field caret positions track valid scalar boundaries; display remains bounded,
control characters are escaped, and exceeding the explicit field capacity reports
`LimitReached`. These simple fields are not substitutes for embedded full editors.

Focus and hover are separate. Input follows modal → capture/popup → child → panel
→ global, stopping after consumption. A modal consumes even an unhandled key,
preventing typing beneath it. Definition-only popup pass-through remains possible;
usage/completion owners can consume their documented keys. Modal stacking restores
previous focus and clears drag capture. Buttons have distinct half-open hit boxes;
field → OK → Cancel traversal works even when only one active control fits on screen.

## Validation

Seven widget tests pass, including real cell assertions for scrolled fields,
explicit carets, selected tab and tiny OK/Cancel rendering. Tests cover theme
inheritance/overrides, Unicode/reverse field selections, clipboard/paste/read-only
guards, modal focus, outside drag release, scrollbar track repositioning, neighbor
hit rejection, clipped panels and standard lists/tables at normal, 20×6, 2×5,
1×1 and empty bounds. Child consumption of Ctrl+Enter prevents a host/global action.
