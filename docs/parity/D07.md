Implemented boundary:

- `panels/database/tree.rs`: inert application-thread explorer reducer with
  datasource status, tagged lazy loads, refresh/collapse, reconnect invalidation,
  stale-result rejection, visible errors, keyboard/mouse actions and clipped
  rendering. Actual connection statuses trigger initial root loading. Drawing
  reuses flattened rows instead of cloning the entire tree on each repaint.
- `object_menu.rs`: source DDL/SELECT/CALL/name SQL actions, keyboard selection,
  mouse buttons and small-screen rendering.
- `connection_dialog.rs`: bounded shared text fields, password masking, all 59
  driver choices, version/class/coordinate/repository/local-JAR fields, context,
  autocommit/read-only, public properties and private credential references,
  grouped URL suggestions, tagged completion and validation preserving caret and
  entered values. Drafts retain unknown persisted fields and existing references.
- `app/runtime/database.rs`: inert configuration/services boundary; async native
  connections/metadata plus blocking config/credential/recents workers. Save closes
  even equal definitions before changing private credentials. New passwords use
  fresh references; failed definition publication cleans up the owned new entry
  while preserving the old working reference. Delete/replace preserves shared
  references until their last datasource is gone.
- `controller.rs`, AppRuntime/AppState/runner: Alt+6 panel, lazy configuration
  reads, async tagged JDBC jobs, CRUD/test/download and nested driver progress
  modal, native clipboard proofs, focus restoration, SQL editor-host launch,
  explicit service restart (`R`), and workspace shutdown/rebinding are wired.
  Session folders open/remove real shared editor documents; switching sessions
  preserves text and view state. No SQL runs merely from opening a session/menu.

The explorer rejects old workspace/node replies and checks the native cache again
before publication. Refresh prunes obsolete descendants and cancels their loads;
collapse releases the display subtree. Retention is bounded to 256 loaded nodes,
50,000 objects and 32 MiB estimated object storage, with visible capacity/nesting
errors. These are display bounds, not hard process RSS guarantees. Java metadata
can continue on its owner after native cancellation until return or teardown.

Save/deletion acknowledgements are critical jobs and finish before workspace exit.
Other new database work is rejected during closure. Services stop metadata and
connections/helper before joining scheduler work; workspace switches create fresh
service ownership and invalidate old tags. Configuration errors remain in the
database panel, leaving native file editing and saves operational. Authentication
feedback includes bounded redacted SQLSTATE/vendor/message details; passwords stay
masked and private values never enter public definitions or session backups.
