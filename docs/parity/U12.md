including named and empty package versions, nullable statement versions and
distinct binary `UNIQUE_ID` values. The source lookup accepts both `NULL` and
empty statement versions for an unversioned package while retaining the bound
schema/name/unique-ID identity. [IBM's package catalog](https://www.ibm.com/docs/en/db2/12.1.x?topic=views-syscatpackages)
defines `PKGVERSION` as non-nullable, while its [statement catalog](https://www.ibm.com/docs/en/db2/12.1.x?topic=views-syscatstatements)
allows nullable `VERSION`. This is not

request and offers source without fabricating a DDL action; that fixture is not a
native Db2 TUI replay.
