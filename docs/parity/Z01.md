Ctrl+T requests shell suspension before modal/editor routing. The sole terminal
owner disables input/raw/mouse/alternate/paste/focus modes, launches the selected
shell with inherited terminal and workspace cwd, and resumes on success or launch
failure. Nonzero exits and missing executables produce notices. Resume failure
uses terminal recovery/persistence and child cleanup. Pending clipboard reads
are cancelled and their interactive proofs discarded; remembered copies retain
publication. In-memory documents, caret and feature owners survive suspension.

The serve adapter resolves an explicit `KODE_TTYD`, an adjacent executable or PATH.
It preserves original loopback/11045 defaults, explicit public/host/credentials,
port aliases including `--post`, literal forwarding boundaries, writable mode,
terminal type and cwd. Its child is the current Rust executable, with optional
absolute resource override. Unix exec removes any intermediate wrapper and
retains ttyd's PTY/signal ownership. Missing/unusable launchers fail explicitly.
CLI Debug/errors exclude credentials; normal credentialed invocation suppresses
ttyd notices, which otherwise print a reversible Basic auth token.

SIGHUP/SIGTERM use the same close/persist/quiesce route as Ctrl+Q, even when the
window is unfocused. Actual browser disconnects preserve unsaved file/SQL buffers,
cancel streams and reap the Rust child and external JDBC helper. The existing
ttyd/xterm frontend supplies browser clipboard and selection; no new web frontend.
