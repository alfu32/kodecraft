# Z02 — Settings, help, about and operational status

Status: done

Source baseline: `7d3e5953ec2de75f2b5e9c44fb3e65549d39ec68`, clean.
Prerequisites W05/L09/P01/D07/F05 are done. Read SettingsView, HelpView,
AboutView, Main's performance/status rendering and native worker/LSP contracts.
Qualified on Linux x86_64 with Rust/Cargo 1.99.0 stable. Other platform runtime
qualification belongs to Z04; no untested platform result is implied.

Settings has LSP/Index sections selected by Tab or mouse. Native Rescan/Rebuild/
Clear use the existing worker, expose actual scan/extract/resolve/persist phases
and counters, and leave user JDBC connections and dirty buffers intact. Wrapped
text panels cache layout, scroll at tiny sizes and map wrapped action lines to
source commands. LSP lifecycle/install owners remain acknowledged and unchanged.

Help derives its scrollable content from the command catalog consumed by global,
editor, search, file/project, Git, SQL, REST, image/hex and settings reducers. It
explains scoped conflicts and focus. Search Ctrl+Enter retains priority over host
execution. At this checkpoint Alt+F opened file find and Ctrl+Shift+F project
search. The finalized UAT subsequently superseded that preference: [U01](U01.md)
owns Ctrl+F file find and Alt+F project search, with optional project aliases.

The sidebar has one horizontal header in source order: Files, Project, Git,
Database, REST, About, Settings, Help (UAT M001). Semantic panel constants preserve
existing Alt+1..8 actions despite visual reordering. Clicking a tab focuses its
actual panel. The content uses the full sidebar width beneath the header.

About includes build version, MIT license/source, actual locked Rust dependency
credits, Java/helper and native library credits, and loaded definition/grammar
languages. Credits and languages scroll independently; Tab selects the list and
mouse selection marks a language. Tiny panels display the focused list, without
leaving hidden hit targets. `scripts/credits.py --check --offline` verifies all
458 locked dependency entries at the Z02 checkpoint (505 after M002 additions), including build/test/target dependencies. Ordinary
builds consume the checked-in JSON without running Cargo metadata during paint.
The original root MIT license is preserved verbatim in LICENSE.md. Full bundled
license texts and native manifests belong to Z03.

Process samples run in at most one owned background job. RSS is resident memory
of the Rust process; CPU uses accumulated process CPU time over elapsed time,
normalized to available logical CPUs. Initial/unavailable CPU is unknown, not a
fabricated zero. The status displays actual loop and draw rates; native settings
also exposes metrics in narrower terminals. Samples and counters are not persisted.
The terminal loop keeps polling but draws only on input, notifications, active
pointer capture or the metrics interval. Scan/index/LSP/SQL/REST completion and
progress publication request repaint. No Java is needed for operational status.
