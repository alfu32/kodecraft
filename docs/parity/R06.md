Implemented behavior:

- Alt+7 opens the real collection tree. Keyboard expansion/navigation, page steps,
  `/` filtering with clipboard input, per-row buttons, right/middle context menus,
  add/rename/duplicate/move/delete, nonempty-folder confirmation, Postman replacement,
  chosen-folder OpenAPI import and guarded export reach the actual model/workers.
  Unknown fields, scripts, disabled rows and saved examples survive these actions.
  Tree indices account for unknown JSON children. Expanded paths, selection and
  runtime identities rebase after mutations; restored nested selection opens its
  ancestors. Filter typing and menus own focus. Wheel scrolling is independent
  of keyboard follow, and long context/move menus scroll to every option.
- Import publication checks its captured collection identity and destination.
  Stale menus/imports/pastes cannot modify a replacement collection or another
  field. `!` and Import notices inspect retained conversion metadata from all
  imports, including after restart; blocking incomplete-import markers remain.
  File parsing and export I/O run on workers. Explicit first-time export filenames
  can replace the selected existing regular file using a bounded identity capture;
  subsequent exports retain their previous identity and refuse external changes.
- Environments share the sidebar with a captured draggable divider. Tab switches
  keyboard navigation; create/copy/rename/activate/remove and mouse/menu controls
  preserve typed metadata. The source key/value dialog's calculated but undrawn
  OK/Cancel controls are visible, separate targets in the native implementation.
  Fields are bounded, Unicode-aware and use clipboard ownership proofs. Tiny
  viewports expose only their current accessible target and do not panic.
- Environment buffers use the existing editor/document registry, search,
  selection, history, clipboard and properties grammar. Semantic parsing runs on
  a document-owned worker and publishes only to the exact latest revision.
  Opening another view does not cancel that document's parse. Pending view opens
  defer focus while modals are active and yield to a later file/SQL open.
- Project captures materialize ropes on a worker, merge environment metadata and
  retain comments/unfinished lines in the owned project extension
  `x-kode-rs-environment-buffers`. Large raw drafts are held behind Arcs outside
  the model's unknown-field map. Copy captures the current buffer even before
  semantic publication; staged copies survive immediate quit before view setup.
  Selected path/divider/active environment persist. Invalid REST state remains
  unchanged and its panel refuses edits that could not be persisted.
- The Run action reaches the real sequential native executor over an immutable
  depth-first request selection and current environment buffer. Run again cancels;
  validation fails before networking, and later requests are not sent after stop.
  Cookies are scoped to the workspace. Runtime item keys handle missing/duplicate
  imported IDs without inserting metadata into the collection. Tree moves rebase
  these keys while outstanding responses keep their captured original identity.
  The UI publishes bounded queues (64 progress events, one completed response),
  caches at most 32 responses/192 MiB of conservatively counted captures, and
  shows run progress/completion counts. Disposal cancels blocking body preparation
  as well as network waits; there is no replay. R08 owns the full runner panel.
