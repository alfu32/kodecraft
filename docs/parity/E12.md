# E12 — Reusable editor hosts and virtual/read-only documents

**Status:** done

Source baseline: `7d3e5953ec2de75f2b5e9c44fb3e65549d39ec68`.
Validated on Rust/Cargo 1.99.0 stable, Linux x86_64.

`editor/host.rs` composes the document, input, search, folds/minimap, completion
and navigation widgets behind the EditorHost interface. Hosts supply language,
save capability, providers, change/navigation/execution reducers, warnings and
revision-bound transient highlights. The queued production adapter coalesces
successive whole-snapshot change callbacks. Actual feature reducers attach in
W04/D08/R06/R07; optional intelligence is explicitly absent in hosts without it.

EditorDocuments owns documents and one serialized save controller per document;
views keep separate caret/focus/search/popups over the shared text/history.
Registered response/raw-request/historical roles force read-only at the document
boundary. No public mutable registry document accessor bypasses that guard.
Keyboard, paste, cut, undo, replacement, completion and programmatic editor APIs
all reach core checks. Movement, selection, copy, search and scrolling stay usable.
Shared-document notifications synchronize views and clamp stale caret boundaries.

File saves use E04's physical controller. Virtual saves issue explicit owner-key
jobs; labels never become filesystem paths. Both serialize/coalesce requests and
acknowledge older saved snapshots without clearing newer edits. Distinct document
save owners survive view detachment; removing a document with a save still active
is rejected. Detached views reject pending interactive results and retain critical
save/copy effects for the application to drain. Native clipboard I/O uses bounded
workers; copies remember the shared raw text immediately.

Absolute pane rectangles and original modifiers pass once through nested hosts.
Popup/search controls run before host shortcuts. Focused search Ctrl+Enter gets
find-all; SQL/REST execution occurs only after the child declines and the host
owns focus. Execution callbacks carry the captured snapshot and selection for the
feature's statement/request resolver. Response/result views cannot steal header
editor arrow keys. Painting uses prepared overlays, duplicate warnings and current
transient ranges. Header paths/labels use escaped cell text so control/wide labels
cannot corrupt terminal geometry. Completion and hover services stay outside paint.

Eight host tests cover UX-025/100–106 at the assigned boundaries: mutable SQL/
REST/environment editor behavior, history/language/change callbacks; all response/
raw/history mutation paths including regex/completion/programmatic APIs; shared
clipboard and nested focus/modifiers; search versus host Ctrl+Enter; virtual owner
save labels and older/newer snapshots; shared views/save lifetime; exact warning/
transient cells and hostile/tiny labels; actual file save after detach and native
clipboard worker/fallback. These combine the earlier component tests rather than
claiming JDBC/HTTP execution or project-search services are already implemented.
