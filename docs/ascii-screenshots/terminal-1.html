kode-rs help
Kode terminal IDE
Usage: kode-rs [OPTIONS] [TARGET]
       kode-rs <COMMAND>

Commands:
  version  
  serve    Serve the terminal IDE through an installed or bundled ttyd executable
  help     Print this message or the help of the given subcommand(s)

Arguments:
  [TARGET]  Open a file or folder. A file takes precedence over restored session focus

Options:
      --resources <DIRECTORY>  Override the resource directory (styles, MIME and service catalogs)
  -v, --version                
  -h, --help                   Print help
